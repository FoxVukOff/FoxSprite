## Introduction
FoxSprite is a free and open-source editor for pixel art and sprite animation.

### Key features
- Real-time animation preview
- Onion skinning
- Multi-layer and multi-frame workflow
- Built-in palettes and custom palette editing
- Tiled drawing mode for patterns/textures
- Pixel-precise tools for retro workflows
- Support for multiple sprite/animation formats
